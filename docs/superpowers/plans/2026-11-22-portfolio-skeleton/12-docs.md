````markdown
# Portfolio Website

Nelson Raphael's portfolio: static pages built by Astro, served by Cloudflare Workers, and refreshed nightly by GitHub Actions. [CONTEXT.md](CONTEXT.md) is the full specification.

## Local setup

1. Install the Node version in `.nvmrc`.
2. `npm ci`
3. `npx playwright install --with-deps chromium`
4. `npm run build && npm run pdf && npm test`

No secrets are needed. Without `GH_GRAPHQL_TOKEN`, the build uses fixture data.

## Scripts

| Script | What it does |
|---|---|
| `npm run dev` | Development server. Run `npm run fetch:github` once first |
| `npm run check` | Type check |
| `npm run check:content` | Content schemas and integrity rules |
| `npm run fetch:github` | Writes `src/data/github.json` |
| `npm run build` | Content check, GitHub data, then the static build |
| `npm run pdf` | Résumé and CV PDFs. Run it after `build` |
| `npm run test:unit` | Unit tests with coverage |
| `npm run test:e2e` | Browser, PDF and accessibility tests against `wrangler dev` |
| `npm run test:smoke` | Smoke tests. Set `SMOKE_BASE_URL` to test a deployed site |
| `npm test` | Unit tests, then browser tests |

When an AI agent runs `astro dev`, Astro starts it in the background. Set `ASTRO_DEV_BACKGROUND=0` to keep it in the foreground.

## Quality gates

Every change goes through a pull request. The `quality-gate` check must pass: clean install, type check, unit tests with 90% coverage of `src/lib/`, content integrity, build, PDFs, browser tests and accessibility. A code review and the owner's merge follow. Deploys run the same gate.

## Deployment

`main.yml` deploys on every push to `main`. `nightly.yml` runs it every night.

| Name | Kind | Purpose |
|---|---|---|
| `CLOUDFLARE_API_TOKEN` | Secret | From the "Edit Cloudflare Workers" template |
| `CLOUDFLARE_ACCOUNT_ID` | Secret | Cloudflare account |
| `GH_GRAPHQL_TOKEN` | Secret | Fine-grained token with read-only access to public repositories |
| `SITE_URL` | Variable | Public URL. Set it after the first deploy, then rerun `main.yml` |

- **Token expiry:** when `GH_GRAPHQL_TOKEN` expires, deploys fail until it is replaced.
- **Schedule:** GitHub turns off scheduled workflows in public repositories after 60 days without activity. The colophon shows when data was last refreshed.

## Content

- Placeholders are quoted: `"TODO(owner): what is needed"`. `STRICT_CONTENT=true` rejects them.
- Images must be PNG, JPEG or SVG, at most 5 MB, without GPS data. Remove it with `exiftool -gps:all= file.jpg`.
- Photos of people need their consent. Never add identifiable minors.

## Launch checklist

1. Replace every `TODO(owner)` and set `STRICT_CONTENT=true` in the quality gate's build step.
2. Raise `MIN_PROJECTS_PER_TRACK` to 3.
3. Remove `X-Robots-Tag` from `public/_headers`, and its assertion in `tests/e2e/assets.spec.ts`.
4. Remove any A or CNAME record on the apex, then attach the custom domain.
````

````astro
import Base from '../layouts/Base.astro';

<Base title="Colophon" description="How this site is built and tested">
  <h1>Colophon</h1>
  <p>This site is generated by Astro and served as static files by Cloudflare Workers.</p>
  <h2>How it is built</h2>
  <ul>
    <li>Content is MDX and YAML, validated against typed schemas and integrity rules.</li>
    <li>Résumés and the CV are PDFs generated from the same content.</li>
    <li>Pages ship no client-side JavaScript.</li>
  </ul>
  <h2>How it is tested</h2>
  <ul>
    <li>Unit tests cover the content rules, with a 90% coverage threshold.</li>
    <li>Playwright checks every route, link, header and PDF on desktop and mobile.</li>
    <li>axe checks every page for accessibility violations.</li>
    <li>The same quality gate runs on every pull request and before every deploy.</li>
  </ul>
  <h2>How it is updated</h2>
  <p>Data refreshed: <time datetime={fetchedAt}>{fetchedAt}</time> (source: <span data-testid="source">{source}</span>)</p>
</Base>
````
